# Folia DOM 歌词效果

莫奈、云阶和流光使用 Folia 固定提交 `a8885a87539b92fb1149fc58ef0f033ad65ec042` 的排版、运动参数与时序算法。原作者 chthollyphile，上游 [chthollyphile/folia-major](https://github.com/chthollyphile/folia-major)，遵循 AGPL-3.0。

## 导入与适配

```sh
node scripts/vendor-lyric-dom.mjs /path/to/folia-major
```

带生成标记的 `vendor/` 文件由脚本导入，不直接修改。脚本将 React、Framer Motion 的类型替换为算法实际使用的契约，复用 `LyricPV/vendor` 中同一提交的分词、时间、颜色和测量工具。流光的排版仍位于上游 React 组件中，脚本提取其纯计算体。`vendor/types.ts` 是本项目维护的契约，无生成标记。

上游当前云阶的排版虽然保留 `columns` 结构，实际会把生成的块放进一列；宿主保留该算法以及每块的缩放、错落和块内逐词运动。旧移植中“最多三行”的本地简化不再用于播放器。

`model.ts` 只在宿主边界将 AMLL 毫秒数据转换为上游的秒。随机布局的种子也使用秒，普通歌词不生成虚构的逐词时间。原始翻译、罗马音、点击跳转及歌曲偏移继续由现有播放器适配。

## Vue 宿主

- `GlowStage.vue` 共用于云阶与流光，只在换句、尺寸或设置变化时更新结构。保留上游文字重叠计算，依据容器和文字实际尺寸整体收缩，适应半屏歌词布局、纯歌词模式与设置预览。
- `useWordMotion.ts` 直接订阅播放器时钟，按上游三态目标、弹簧参数和逐字辉光参数更新 DOM。只有状态变化启动运动帧；文字阴影保持固定半径，以透明度驱动辉光。
- 莫奈仍由 `Monet/MonetLyricRail.vue` 管理轨道及滚轮、触摸浏览，`Monet/useMonetMotion.ts` 使用上游布局与实测字形宽度驱动扫光。独立辉光层只改变透明度，字体加载时清理测量缓存。超长解析词使用已有字形时间拆成可换行单元。

暂停停止运动帧，隐藏时停止高频样式写入，卸载清理帧回调和字体监听。恢复、回拖及减少动态效果时重新同步姿态。播放器原有的字体、翻译、罗马音、逐字动画和各效果设置继续生效。

本次只移植歌词效果，不接入 Folia 的海报、背景、AI 服务或 React 运行时。动画由 Vue 宿主驱动，不能以源码复用推断逐帧像素完全一致。

## 验证

`model.test.ts` 验证秒制边界、真实字形时间、布局缓存、重叠歌词、短句时序和容器缩放；`useWordMotion.test.ts` 在 Vue 生命周期中验证暂停、跳转、隐藏、减少动态效果及卸载。莫奈长词时间回归位于 `Monet/upstream.test.ts`。

浏览器验证使用生产 Vue 组件，覆盖 330px 窄区域与宽区域、长句换行、暂停、回拖、换句及设置页预览。临时组件更新计数确认同句内高频时钟不触发 Vue 更新；调试节点和计数均只注入测试浏览器，没有写入生产源码。桌面 mygo 原生窗口与 Folia 同曲逐帧对照仍需单独验证。
