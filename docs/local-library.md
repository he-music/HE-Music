# 本地曲库与已下载播放

## 本地歌单

桌面端在侧栏「创建的歌单」旁点击加号，创建弹窗顶部可切换「在线歌单／本地歌单」。
本地歌单显示在同一侧栏，带有「本地」标识；点击进入独立详情页 `/local-playlist?id=…`。
详情页沿用在线歌单的封面、标题、简介、搜索和歌曲列表，支持编辑名称、封面和简介。
本地歌曲菜单与批量操作均提供「添加到歌单」；详情页右键可调整顺序或移除歌曲，更多菜单可
批量移除歌曲或删除歌单。这些操作只修改歌单记录，不删除音乐文件。

创建和编辑本地歌单时可选择本地图片、预览、移除封面，也可使用图片链接。
支持不超过 10 MB 的 JPEG、PNG、GIF、WebP 图片；导入时按比例缩小到最长边不超过 1024px，
转换为静态 JPEG（透明区域使用白色背景），图片数据随歌单持久化并进入应用数据备份。
原图片移动或删除不会影响已保存封面；取消编辑不会修改歌单，也不会留下单独的图片文件。

歌单使用现有 `music-data/music` 数据库的 `localPlayList` 键保存，沿用应用数据备份和恢复。
写入按顺序执行，成功后才发布状态；写入失败保留当前列表，可重试。数据损坏时保留原始记录，
不自动覆盖为空歌单。歌曲只保存稳定 ID 和展示字段，不保存原生授权或运行期对象。

播放时通过当前曲库重新解析文件。文件移动、目录失效或尚未扫描时显示「文件不可用」，
不能从旧路径直接播放。重新扫描或恢复目录后，原位置的文件会恢复可用；文件换了位置时，
可点击「重新关联」手动选择当前曲库中的歌曲。重新关联保持歌单中的顺序，并阻止重复歌曲。

## 已下载优先播放

「设置 → 播放设置」提供「优先播放同音质已下载文件」，默认开启，仅桌面端显示。
在线歌曲按原平台、歌曲 ID 和选定音质匹配已完成下载记录，再从当前授权曲库取得对应文件。
播放前使用本地网关 HEAD 请求确认文件可读，全部候选的预检总预算为两秒。

没有匹配文件、音质不同、授权失效或文件已被删除时，沿用在线取源。
文件读取或解码失败时，当前进程会跳过该副本版本并回退在线，保留进度和最新播放意图；
输出设备或引擎错误仍按原有逻辑处理。歌曲身份不变，因此历史记录和歌词偏移继续对应原歌曲。
下载文件中存在歌词时直接读取文件歌词，不依赖在线歌词请求。

此匹配依赖下载记录与文件之间的关联。清理下载记录后，音乐文件仍属于本地曲库，
但该记录提供的在线歌曲关联不再参与优先播放。

## 自动同步

本地音乐页面和本地歌单详情页恢复前台时检查曲库变化，连续可见时每分钟检查一次；聚焦检查间隔至少五秒。
隐藏、离开页面或卸载时停止检查，并取消该页面自己的扫描，不取消后来发起的手动扫描。
手动扫描、下载、文件写入或原生文件面板占用期间不启动自动检查。

同步沿用现有受限扫描和元数据缓存，不增加系统目录监听器。自动扫描复用未变化条目，
仅发布发生变化的曲库数据；原生引用变化仍须正常发布。独立封面和歌词旁挂文件需要主动
刷新时，使用原有扫描按钮，保留手动刷新资源 URL 的行为。
