# mygo Windows 实测清单

当前状态：尚未在 Windows 主机构建或运行。macOS 上的构建、fake 测试和 Windows 静态交叉编译不能替代以下验证。
按用户授权，本轮不执行 Windows 实机测试；待功能迁移完成后统一执行本清单。

## 准备与构建

- [ ] 使用迁移分支和同一 `pnpm-lock.yaml`，安装 Node 24 LTS（最低 24.12.0）、pnpm 10.28.1、Go 1.27.3。
- [ ] 确认 `go version`、`node --version`、`pnpm --version`，记录 Windows 版本与 CPU 架构。
- [ ] 确认 WebView2 Runtime 可用；记录未安装时的提示与恢复方式。
- [ ] 执行 `pnpm install --frozen-lockfile`；不需要执行旧 Electron 的 `install:electron-deps`。
- [ ] 执行 `pnpm run build:web`，使用独立静态服务部署 `dist/web`，确认根路径静态资源和 hash 路由可用。
- [ ] 执行 `go tool mygo doctor` 并记录结果。Windows 安装器需要 NSIS，签名工具缺失与运行依赖分开记录。
- [ ] 执行 `go tool mygo build -platform windows/amd64`，检查 `build/mygo/windows-amd64` 的可执行文件和安装器；ARM64 设备另用 `windows/arm64` 验证。
- [ ] 检查安装包与安装目录，不包含 Node、Electron、`app.asar` 或旧 Node 服务；运行时不创建 Node/Electron 子进程。

## M1 窗口与资源

- [ ] `pnpm run dev:desktop` 可启动 Vite 和 mygo 窗口，关闭开发命令后不残留应用或开发服务。
- [ ] 构建后的程序脱离仓库、Node、pnpm 和开发服务器后仍能启动并加载共享 Vue 页面。
- [ ] 在含空格和中文的路径运行，验证字体、图标、懒加载页面和窗口缩放。
- [ ] 验证 Windows 的 `http://mygo.localhost` 资源 origin；后端必须允许所需的 origin，不能照搬 Electron 关闭同源安全的假设。
- [ ] 首次启动、关闭与再次启动不异常；单独记录旧设置或旧播放列表造成的行为。

## M2～M5 后续交接验收

M2 已在 macOS 实施并完成隔离 WKWebView 探针；以下 Windows 项目仍需用户实测，认证、播放与歌词按 M3～M5 完成后逐项测试。

- [ ] 未接入的桌面能力不阻断启动；不出现无实现的 Electron IPC 调用。
- [ ] mygo 原生标题栏的最小化、最大化/还原和关闭正常；页面不重复显示 Electron 自定义窗口按钮。
- [ ] 托盘不可用、尚未就绪或页面卸载后关闭最后窗口可退出；旧关闭、歌词、本地播放列表配置不会造成后台滞留。
- [ ] 系统平台识别为 win32；WebView UA 不会让 mygo 走 Electron IPC；HTTP(S) 外链由系统浏览器打开，非 HTTP(S) 外链被拒绝。
- [ ] 最大化事件在多次进入/退出布局后仍只回调一次，卸载后监听解除；最小化和重新显示不丢失必要界面状态。
- [ ] 使用现有 HE-Music 后端验证密码登录、扫码登录、刷新令牌与登出。
- [ ] 对后端动态列出的每一种第三方授权分别验证：系统浏览器打开、loopback 回调、state 兑换、取消、超时与再次登录。记录 provider 名称和结果，不保存令牌或 Cookie。
- [ ] 验证开发与生产 origin 的后端 CORS、授权 redirect 与本地存储；不能用开发成功代替生产验收。
- [ ] 验证在线播放、暂停、切歌、进度跳转、重定向、Range 和实际歌曲格式，记录 WebView2 媒体差异。
- [ ] 验证普通、AMLL、Monet 歌词效果，以及半屏歌词布局和纯歌词模式。
- [ ] 实际播放可闻歌曲，区分显式点击成功与首次异步取源/自动播放策略拒绝；拒绝后当前曲目保留，后续点击可恢复，不自动循环切歌。
- [ ] 播放中与暂停中 seek、恢复记忆进度；快速切换前后首和迟到取源，声音、标题、歌词对应当前歌曲。
- [ ] 普通、AMLL、Monet 逐项验证普通 LRC 与逐字歌词，高亮随时间和偏移更新、点击歌词跳转；暂停时 seek、换歌词、效果和设置仍更新。
- [ ] 半屏歌词布局保留封面，切纯歌词模式、缩放窗口和字体后不溢出；分别保存无敏感截图。
- [ ] 最小化或隐藏、恢复、关闭播放器后 RAF、ResizeObserver、IntersectionObserver 不重复订阅且正常清理；普通/Monet 暂停时无持续空转，AMLL 暂停保留 core 原有动画语义，节流改进留待后续升级。
- [ ] 记录真实 MP3、FLAC 等编码及 HTTPS、HTTP、重定向、Range、失效音源差异；macOS 静音 WAV 合成结果不能替代 WebView2 验收。
- [ ] 在无 Node、无旧网易/解灰服务的环境再次验证在线使用。

## 托盘与关闭生命周期（迁移完成后统一实测）

- [ ] 托盘图标正常，显示主窗口可恢复隐藏或最小化的窗口。
- [ ] 默认原生关闭仅出现一次提示；取消保留窗口，提示停留超过 5 秒不会被强制退出。
- [ ] 记住隐藏后原生关闭不再提示，托盘可恢复；记住退出后真正退出。
- [ ] 托盘上一首、播放/暂停、下一首各执行一次；无歌时禁用，本地歌曲保护保留。
- [ ] 托盘退出、系统退出绕过关闭提示，释放托盘、监听和授权回调资源。
- [ ] 托盘初始化失败、前端尚未就绪或卸载后关闭不被拦住，隐藏入口不可选。
- [ ] 应用壳卸载、重挂载不重复事件；播放进度和歌词时钟不触发托盘 IPC 同步。

## 全局快捷键（迁移完成后统一实测）

- [ ] 默认 globalOpen 和播放/暂停、前后首、音量五动作在后台或隐藏时各执行一次。
- [ ] 全局录制获得焦点时暂停；失焦或组件卸载后按最新配置恢复。
- [ ] 并发录制、录制中关闭开关、重置、应用壳重挂载不恢复旧配置或留下注册。
- [ ] 冲突、无效组合及系统拒绝得到实际反馈；本服务查询不冒充跨应用占用查询。
- [ ] Ctrl 与 Command/Windows 键区分正确；页内焦点防护、本地音频保护保留，不重复执行。
- [ ] 退出、页面失效或卸载后清理全部本服务拥有的注册，不影响其他组件或应用。
- [ ] 单独记录真实 OS 按键触发；程序定向事件不能替代此项。未实现的桌面歌词动作不注册。

## 系统媒体与防休眠（迁移完成后统一实测）

以下全部尚未在 Windows 执行；macOS `nativeprobe,mediaprobe` 的程序 callback/API 计数不能替代这些项目。

- [ ] 确认系统媒体 `smtcOpen` 默认开启，反复关闭/开启后只有当前壳的一组订阅与元数据，不与页面 Web MediaSession 重复发布；Web/Electron 的既有路径分别保留。
- [ ] 真实 OS 媒体控件的播放、暂停、上一首、下一首、跳转分别执行一次；包括播放中和暂停时 seek 到 0。记录 OS 输入与程序 callback 的证据区别，不向其他应用注入命令。
- [ ] 切歌、改标题/艺人/专辑、切实际倍速（含非 1 倍速）及未知时长后状态正确；普通进度自行推进，歌词/进度时钟不持续发布 metadata/配置/注册。
- [ ] 无歌、本地歌曲、快速切歌、旧代际/旧曲目回调及应用壳卸载/换壳不误控新歌；原生拒绝不阻断 HTMLAudio 播放。
- [ ] 防休眠默认关闭，实际 provider 可用时可开启。仅用户显式开启且长期壳 Ready 时持有 display lease；暂停、隐藏/显示、关闭系统媒体不释放或重复获取它。
- [ ] 关闭防休眠、退出、页面 context 撤销和壳卸载后释放本服务 lease/媒体订阅；旧壳清理不撤销新壳。实际显示器休眠试验单独记录，API 请求成功不等于 OS 阻睡眠已验证。
- [ ] 在普通打包 origin 检查系统媒体 Artwork 的实际 OS 显示及真实图片/CORS；覆盖 PNG/JPEG、缺图、超预算、快速切歌、同曲目换图、迟到图像、倍速新版本、关闭/重开与卸载清理。本次 macOS 开发探针仅证明自产 PNG 到达 NowPlaying 模块及生命周期，不能把播放器/Web 封面或模块快照视为 Windows 系统封面验收。

## 设置文件与目录授权（迁移完成后统一实测）

当前代码已接 Go 与前端设置入口，普通 Web/macOS 构建通过；macOS 三轮隔离探针均在启动弹层准备失败、picker 0/0，不能视为文件交互通过。Windows 以下项目全部未执行。

- [ ] 在实际构建命令及其前端子进程环境核验 Node 24、pnpm 10.28.1、Go 1.27.3，不能只检查另一终端。首次 Mac 子进程误用 Node 25 的历史结果不作为合格验收。
- [ ] 实际 Open/Save 对话框附着主窗口；取消静默且不改设置，错误明确提示，不输出文档内容、路径或账户数据。
- [ ] 合法当前、partial 和受支持 legacy renderer 文件可导入；只处理 setting-store/shortcut-store，Electron/native/auth 段不恢复。未知键、错误枚举/字体/数组、损坏/超量文件整体拒绝，第二 store 非法不先写第一。
- [ ] 存储 quota/写入失败时不 reload，尽力恢复旧值；回滚失败提示不冒称完全恢复。成功到 reload 的等待期保持按钮禁用。
- [ ] 从歌词入口打开设置、切 General、切语言、关闭；旧确认、迟到导入/失败及保存结果不写入或提示，关闭前的 reload timer 被撤销。路由设置页单独实测，不能仅凭 MainSetting 的 Node 渲染测试覆盖。
- [ ] 文件操作 Busy 不堆面板；壳替换、未知 epoch begin 迟到、挂起面板期间 teardown 和旧清理不撤销新会话。现 SDK 无取消 handle，撤销不保证立刻关闭已显示面板。
- [ ] 用自产 JSON 副本验证只接受本次原生选择路径、普通文件/符号链接限制，以及 Windows ACL、占用、同目录临时件/rename 失败保留原件和清理。撤销先赢不得提交，commit claim 先赢允许该次替换完成；不将其称强取消事务。
- [ ] 后续目录 UI 接通后再验证 Unicode/大小写/卷/父子与 symlink 身份、opaque token 及释放。默认显示路径、导入 raw 路径和旧 token 不授权限；当前没有持久授权，不能宣称跨重启恢复。
